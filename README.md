## Time-Series-Analysis: Nigeria CPI and Naira-USD Exchange Rate.
## Overview
This project analyses two Nigerian monthly series:
1. Nigeria Consumer Price Index (CPI)
2. Naira-USD Exchange Rate

The analysis focuses on understanding trend, seasonality, autocorrelation, decomposition, transformations and seasonal adjustment before forecasting.

## Objectives
- Examine the time-series structure of both series.
- Identify trend and seasonality.
- Analyze autocorrelation using ACF.
- Compare additive and multiplicative structures.
- Perform classical and STL decomposition.
- Assess the need for transformation.
- Obtain seasonally adjusted series.
- Quantify trend and seasonal strength.
- Develop managerial insights and forecasting cautions.
